## 二、在另一台电脑怎么用（迁移 5 步）

### Step 1 · 搬代码
两种方式任选其一：
- **Git（推荐，支持并行）**：`git clone <repo> 07_一人公司出海项目`，目标机器用分支 `dev-pc-b` 隔离。
- **整包拷贝**：把 `07_一人公司出海项目/` 复制过去，**排除** `node_modules/`、`.next/`、`.vercel/`、`.env*`、`*.log`（含密钥，勿明文传）。

### Step 2 · 装依赖（见 03 详述）
- Node 22+（managed 或系统）、Python 3.11（hermes venv 或等价）
- FFmpeg 8.x（**注意：默认不在 PATH，需放 `C:\tools\ffmpeg.exe` 或显式写全路径**）
- `pip install edge-tts`（免费，无需 Key）
- ImageGen 能力（由 WorkBuddy/CodeBuddy 提供，用于生成背景图）

### Step 3 · 修复硬编码路径
本机脚本写死了路径，必须替换（全局搜索替换即可）：
- `C:\Users\lixingliang\...` → 目标机器的用户目录
- `e:\AgentCPM\07_一人公司出海项目` → 目标机器实际路径
- `C:/tools/ffmpeg.exe` → 目标机器 ffmpeg 路径

### Step 4 · 跑通一本新书（最小验证）
1. 在 `output/<新书代号>/` 下建 `source/scripts/`、`images/`、`publish/`。
2. 把 04 的 `render_topic.py` 与一份 `topic_<代号>_douyin_a.json` 拷进去。
3. 准备 6 张背景图放 `images/`（hook/pain/method/case/trust/cta.png），书封放 `source/scripts/book_cover.png`。
4. 跑一遍 A 版渲染，确认出片、含音轨、>1MB、1080×1920。

### Step 5 · 并行创作
两台电脑各认领不同书/不同平台，**统一用 Git 分支隔离**，定时互推。详见 07 的账号矩阵与 01 第四节。

## 三、给 AI 的一句话任务模板

> 我要为图书《【书名】》（【作者】）制作 6 平台 × A/B 双变体带货短视频，复用《AI实操 引流变现8步法》已跑通模式。请走视频生成团队 SOP（主理人→灵阅→灵枢→灵映），参考 `output/图书带货_可复用知识包/` 的方法论、脚本与配置模板，输出 12 个 MP4 + 标题简介总表 + 发布清单。详细 prompt 见 02 第六节。

---

## 四、并行创作的两条铁律

1. **Git 唯一真相源**：两台机器都从同一远程拉取/推送，分支隔离（`dev-pc-a`/`dev-pc-b`），避免互相覆盖。`.env*` 各机独立，不入库。
2. **视频账号隔离**：A 版给主号、B 版给副号；同一平台 A/B 永不同号；不同 WiFi/设备/实名；同平台错峰 ≥15 分钟。限流恢复见 07。

## 五、已知边界（别踩）

- 本包**不含**已渲染的成片（GB 级），需用 Git/硬盘整体搬运 `output/<代号>/publish/`。
- 乐享知识库（本文档所在）以**文档/脚本代码**为主，**视频大文件请走 Git 或云盘**，不要试图塞进知识库。
- 当前渲染器是「AI 生成 + 配音 + 字幕 + 书封叠加」的低成本模板化方案；要更高质感请用真数字人/真人出镜（见 02 与 `视频带货知识沉淀/数字人视频带货跑通方案_2026.md`）。
