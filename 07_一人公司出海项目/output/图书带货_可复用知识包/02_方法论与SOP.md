> 本文把「视频生成团队 SOP」「六平台 × A/B 双变体」「五段口播骨架」「爆款四因子」「分平台规范」「可直接复制的 prompt」集中到一篇，作为新书创作的指挥手册。
> 详细平台规则与合规见 07；脚本与配置见 04；避坑见 05。

## 一、视频生成团队 SOP（四阶段，主理人编排）

主理人（凌导）严格按阶段调度，成员产出须经主理人中转，不得跳步、不得代写、不得成员直连。

| 阶段 | 负责 | 输入 | 产出 | 质检点 |
|---|---|---|---|---|
| 0 建队 | 主理人 | 用户需求 | TeamCreate（命名 `ling-<代号>`） | 团队先建，再 spawn 成员 |
| 1 采集（灵阅） | 灵阅 | 书名/作者/卖点 | Markdown 采集报告（≥5 条，含来源URL/要点/金句/评分） | 相关、有评分、近 90 天优先 |
| 2 策划（灵枢） | 灵枢 | 采集报告 | `ling_planner_pack_<代号>_v1.json` + 标题简介总表 + 发布清单 | JSON 完整、字数达标、A/B 四维不同 |
| 3 制作（灵映） | 灵映 | 策划包 | 12 个 MP4（1080×1920、含音轨） | >1MB、时长达标、有 AI 标识 |
| 4 交付 | 主理人 | 全部产物 | 汇报 + 标题简介总表 + 发布清单 | 全量 ffprobe 质检通过 |

**铁律**：用户说什么就是什么；严格按序；每步拿到结果再下一步；问题如实反馈。

## 二、六平台 × A/B 双变体模式（已验证）

每本书产 **6 平台 × 2 变体 = 12 个视频**，A 给主号、B 给副号，严格隔离。

| 参数 | A 版（主号 main） | B 版（副号 sub） |
|---|---|---|
| 时长目标 | 34–40s | 51–61s |
| 口播字数 | 130–150 字 | 190–220 字 |
| Hook 风格 | 强数据 / 痛点 / 结果承诺 | 反认知 / 身份反差 / 体系视角 |
| CTA 风格 | 直接挂车/购买 | 收藏 + 关注 + 评论扣口令领资料 |
| 背景图 | 根 `images/`（6 张通用） | `source/scripts/images_b/`（差异化英雄图） |
| 命名 | `<平台>_a_main_<时长>s.mp4` | `<平台>_b_sub_<时长>s.mp4` |

**A/B 四维必须不同**：hook 文案、cta 文案、hook 背景图、cta 背景图。差异不足是限流主因（见 07）。

**渲染变体控制**（环境变量）：
- `SIYU_VARIANT=a|b`（默认 a）
- `SIYU_PAUSE`（句间静音秒）：A 用 `0.12`，B 加大到 `0.35–0.50` 以拉长到 50–60s
- `SKIP_TTS=1`：复用已有配音/字幕缓存，只重渲画面（改背景图后必用）

## 三、五段口播骨架（内容质量底线）

| 段落 | 职责 | 示例（图书带货） |
|---|---|---|
| ① 直接进现场 | 0 秒进场景 | "现在是早上6点，我刚改完第3版脚本。" |
| ② 完整过程 | 不剪狼狈 | "先打开书，第3章直接给我 8 步清单。" |
| ③ 真实阻力 | 现实小失败 | "很多人买了一堆AI工具，却变不了现。" |
| ④ 情绪瞬间 | 不演的真实 | "缺的不是工具，是体系。" |
| ⑤ 继续向前 | CTA | "左下角小黄车，8步法直接带走。" |

- **3 秒钩子必须踩中爆款四因子之一**（差异化 / 热点 / 情绪价值 / 实用价值）。
- **开头第一句即冲突/悬念/反常识**，产品尽量首帧可见。
- 字数：60s ≈ 140–160 字；30s ≈ 70–90 字（见 04 配置样例）。

## 四、分平台规范速查（一稿一平台，勿套同一视频）

| 平台 | 时长甜点 | 核心指标 | CTA 形式 | 话题数 | 合规要点 |
|---|---|---|---|---|---|
| 抖音 | 15–60s | 完播率 | 小黄车/主页群聊 | 3–5 | ≥500 有效粉才能挂车；AI 必标 |
| 视频号 | 30–90s | 点赞+转发 | 加微信/公众号/商品卡 | 2–3 | 数字人直播封号；须真人 |
| 小红书 | 30–90s | 收藏率 | 口令+群聊（**零挂链**） | 5–10 | D-09 不挂链；AI 必标 |
| B站 | 3–10min | 完播/弹幕 | 三连+蓝链 | 2–3 | 信息密度高；AI 必标 |
| 快手 | 15–60s | 互动率 | 关注/小黄车 | 3–5 | 老铁真实感；AI 必标 |
| 公众号 | 1500–3000字 | 打开/分享 | 阅读原文/商品卡 | — | D-11 不代写；AI 辅助需说明 |

## 五、爆款四因子（每条内容至少命中 1 个）

1. **差异化（新颖）**：身份/角度反差（"采矿博士用AI写综述"）。
2. **结合热点**：蹭当下流量（AI 新规、毕业季、职称季）。
3. **满足情绪价值**：共鸣/治愈/怀旧（普通人逆袭、下班 3 小时的踏实）。
4. **实用价值**：看完能用、能抄作业（直接给提示词/步骤/模板）。

叠加原则：差异化 + 情绪价值最容易出圈；实用价值决定收藏率。

## 六、可直接复制的 prompt 模板

### 6.1 完整工作流（交给 AI 开新书）

```
我要为图书《【书名】》（【作者】）制作 6 平台 × A/B 双变体带货短视频，
复用《AI实操 引流变现8步法》已跑通模式。

### 背景信息
- 书名：
- 作者：
- 核心卖点（3-5 条）：
- 目标人群：
- 最强 hook（数据/反认知/痛点）：
- 书封图片：□ 是（路径：） □ 否
- 目录/章节：□ 是 □ 否

### 执行要求
1. 走视频生成团队 SOP：建队→灵阅采集→灵枢策划→灵映渲染→主理人交付。
2. 参考 `output/图书带货_可复用知识包/` 的方法论、脚本、配置模板。
3. 输出：12 个 MP4（1080×1920、含音频、A 34–40s、B 51–61s）
   + `publish/标题简介总表.md`（标题/简介/话题/路径）
   + `publish/发布清单_纯文本.md`（按平台分块可直接复制）
4. 规范命名：`{平台}_{a|b}_{main主号|sub副号}_{时长}s.mp4`
5. A/B 四维必须不同：hook 文案、cta 文案、hook 背景图、cta 背景图。
6. 合规：禁用绝对化词；AI 双标（发布页勾选 + 前5秒弱标识）；小红书零挂链；抖音 B 副号<500粉不挂车。
7. 复用 `render_topic.py` 渲染器；整理 `docs/全流程prompt复用指南.md` 方便下次复用。
```

### 6.2 给灵阅（采集）

```
任务：为图书《【书名】》采集带货短视频素材
要求：
- 采集 15-25 条高质量内容，时间优先近 90 天
- 覆盖：作者背景/背书、图书核心方法论、行业趋势、用户痛点、
  图书带货对标账号（陈文日记/都靓读书/肖厂长/教育图书矩阵）、六平台标题简介规范
- 输出 Markdown 报告，每条含标题、来源 URL、要点、可引用金句/数据、评分(1-5)
- 开头 ≤300 字核心结论
```

### 6.3 给灵枢（策划）

```
基于灵阅报告，为《【书名】》产出：
1. source/ling_planner_pack_<代号>_v1.json（core_script/core_script_b、platform_variants×6、materials、notes）
2. publish/标题简介总表.md
3. publish/发布清单_纯文本.md
要求：
- A 版 34-40s，B 版 51-61s；A/B hook/cta/bg/时长四维不同
- 五段口播骨架：hook→pain→method→case/trust→cta
- 开头 3 秒最强钩子，中间带真实阻力/情绪瞬间
- 结尾 CTA 分平台（小黄车/小店/口令群聊/蓝链/快手小店/小程序）
- 标题 ≤18 字、emoji 1-3、核心词前置；简介先干货再引导，全 12 条含"关注"引导
- 话题标签按平台规范；合规：禁用绝对化/虚假承诺/站外导流违禁词
```
