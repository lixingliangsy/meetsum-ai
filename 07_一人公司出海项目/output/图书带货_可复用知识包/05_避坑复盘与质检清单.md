## 一、真实案例：A 版背景图回退成纯色（本次修复）

**现象**：新书《AI实操 引流变现8步法》12 视频渲染后，部分视频背景是纯色暗红，没用上新生成的 AI 背景图。

**根因**：
- A 版 6 个 `topic_*.json` 的 `BG_DIR` 写的是 `"../images"`，相对 `source/scripts/render_topic.py` 解析到 `source/images/` —— **该目录不存在**。
- 渲染器找不到背景图，回退成 `color=c=0x6e1010` 纯色背景（见 04 代码 `bg_input()` 的 fallback）。
- B 版 `BG_DIR: "images_b"` 指向真实存在的 `source/scripts/images_b/`，所以只有 B 版用了新图。

**修复**：
1. 把 6 个 A 版配置 `BG_DIR` 从 `"../images"` 改为 `"../../images"`（正确指向根 `images/`，那里有 6 张新图）。
2. `SKIP_TTS=1` 复用已有配音/字幕缓存，重新渲染并覆盖 6 个 A 版视频。
3. ffprobe 全量质检 + 抽帧验证：12 个视频均 1080×1920、含音轨；A 版 36.9–38.0s / 2.93–3.04MB，B 版 48.1–50.5s / 3.99–4.19MB。

**教训**：改背景图后，先确认 `BG_DIR` 解析路径真实存在、目录里有 `hook/pain/method/case/trust/cta.png`，再重渲；重渲后务必抽帧肉眼核对。

## 二、汇总坑表（对照速查）

| # | 问题 | 根因 | 解决方案 |
|---|---|---|---|
| 1 | A 版背景纯色 | `BG_DIR` 路径解析到不存在目录 | A 版用 `"../../images"`，B 版用 `"images_b"`；重渲前确认路径真实存在 |
| 2 | 视频 <1MB（A 版） | `-crf 20` 对平滑静态背景压到 103kbps | 改目标码率 `-b:v 1000k -maxrate 1500k -bufsize 3000k`（04 已写入） |
| 3 | 字幕被放大/错位 | ASS 未显式 `PlayResX/Y` | 强制 `PlayResX:1080 / PlayResY:1920`；中文用 `wrap_cn()` 折行 |
| 4 | 质检假 ⚠️ 分辨率不符 | ffprobe 返回 `1080,1920`（逗号）对比 `1080x1920`（x）不匹配 | 比对前 `replace(',','x')` 或分读 `width`/`height`（见第三节） |
| 5 | ffprobe/ffmpeg 找不到 | 不在 PATH | 写全路径 `C:\tools\ffmpeg.exe` / WinGet Links 下 `ffprobe.exe` |
| 6 | ImageGen 同图覆盖 | 并行同名同时间戳 | 串行 + 独立子目录 `g1~g6`，及时重命名 |
| 7 | 后端"150 任务上限"限流 | 并发过高 | 停发养号 7–14 天；错峰重试；单批 ≤10 张 |
| 8 | B 版时长不足 50s | TTS 快/停顿短 | 增大 `SIYU_PAUSE`（0.35→0.50） |
| 9 | B 版超 65s | 口播太长/停顿过大 | 精简 `core_script_b` 或减小 `SIYU_PAUSE` |
| 10 | 书封没显示 | 命名非 `book_cover.png` 或不在工作目录 | 确保 `source/scripts/book_cover.png` 存在 |
| 11 | 同素材被限流 | A/B 差异不足 + 矩阵未隔离 | 严格四维差异 + 账号/设备/IP 隔离 + 错峰 ≥15min |
| 12 | 配音尾部被裁 | `-shortest` 截断 | mux 加 `tpad=stop_mode=clone:stop_duration=10` |

## 三、交付前质检脚本（12 项，已修正逗号坑）

```python
# qc_videos.py —— 放在 output/<代号>/ 下运行
import subprocess, json, os, glob
FF  = r"C:\tools\ffmpeg.exe"
FP  = r"C:\Users\lixingliang\AppData\Local\Microsoft\WinGet\Links\ffprobe.exe"

print(f"{'FILE':<28}{'DUR':>8}{'W':>5}{'H':>5}{'AUD':>5}{'MB':>7}")
for p in sorted(glob.glob("publish/*.mp4")):
    # 时长 + 大小 + 码率
    fmt = json.loads(subprocess.check_output([FP,"-v","error","-show_entries",
        "format=duration,size,bit_rate","-of","json",p]))["format"]
    # 视频流分辨率（注意：返回逗号 1080,1920，需替换）
    vs  = json.loads(subprocess.check_output([FP,"-v","error","-select_streams","v:0",
        "-show_entries","stream=width,height","-of","json",p]))["streams"][0]
    w, h = vs["width"], vs["height"]
    res_ok = f"{w}x{h}" == "1080x1920"
    # 音频流
    try:
        aud = json.loads(subprocess.check_output([FP,"-v","error","-select_streams","a:0",
            "-show_entries","stream=codec_type","-of","json",p]))["streams"]
        has_aud = bool(aud)
    except Exception:
        has_aud = False
    mb = int(fmt.get("size",0))/1024/1024
    dur = float(fmt["duration"])
    print(f"{os.path.basename(p):<28}{dur:8.2f}{w:5d}{h:5d}{'a' if has_aud else '':>5}{mb:7.2f}  "
          f"{'OK' if (res_ok and has_aud and mb>1) else 'CHECK'}")
```
